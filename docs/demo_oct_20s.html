OCT detects
macular edema
Patient uploads an OCT B-scan → DRACO predicts DME stage and helps decide referral urgency.
Primary labels: No / NCI / CI DME (3-class)

Input

OCT B-scan
Cross-section of retina for edema / center involvement.

Output

DME stage
Class probabilities + confidence for human review.

Decision

Urgency
Rule-based fusion with fundus (fundus is separate in this repo).
RETFound OCT backbone
A retinal foundation model (ViT-L) pretrained on large retinal datasets, then fine-tuned on MMRDR DME.
External validation
OEFI
MMRDR-trained model tested on Mexico OCT for binary DME (AUC / sensitivity@95%spec).
Why it matters
center-involving edema
CI-DME is treatment-relevant; OCT provides structural evidence not visible on fundus photos.
Results (best model)
RETFound OCT v2 on MMRDR (primary) + OEFI (external). Metrics reported exactly as in our evaluation scripts.
MMRDR DME (3-class)
F1 = 0.784
Accuracy = 0.890. Classes: No / NCI / CI.
OEFI DME (binary)
AUC = 0.994
Sensitivity@95%spec = 0.970. External generalization.
